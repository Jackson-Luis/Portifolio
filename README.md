# Portfólio — Jackson Luis

Site estático feito com HTML, CSS e JavaScript, pronto para publicação gratuita no GitHub Pages.

## Como publicar

1. Crie um repositório público chamado `Jackson-Luis.github.io` no GitHub.
2. Envie `index.html`, `styles.css`, `script.js` e `profile.png`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O endereço ficará:
`https://jackson-luis.github.io/`

## Antes de enviar para uma vaga

Troque os projetos de exemplo pelos seus projetos reais e, se possível, adicione links para demonstrações funcionando.
